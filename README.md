# オリジナルキャラクター図鑑

Rust と egui/eframe を使用して開発している、オリジナルキャラクターの情報を管理するデスクトップアプリです。

キャラクターのプロフィールや能力を登録し、一覧表示・検索・編集・削除などを行うことができます。

## 概要

**オリジナルキャラクター図鑑** は、自分で考えたキャラクターの設定をまとめて管理するためのアプリです。

キャラクターの基本情報だけでなく、能力の名前・威力・消費MPなども登録できるようにしています。

Rust の学習を兼ねた個人開発プロジェクトとして、データ構造の設計、エラー処理、ファイル入出力、GUIの実装などに取り組んでいます。

## 使用技術

- **言語:** Rust
- **GUI:** egui / eframe
- **エラー処理:** thiserror
- **データ保存:** ファイルによる永続化
- **開発環境:** Windows / Visual Studio Code

## 主な機能

### キャラクター管理

- キャラクターの新規登録
- キャラクター一覧の表示
- キャラクター情報の編集
- キャラクターの削除
- 削除前の確認ダイアログ
- 名前や種族による検索

### プロフィール管理

キャラクターごとに、以下の情報を管理できます。

| 項目 | 内容 |
|---|---|
| ID | キャラクターを識別するためのID |
| 名前 | キャラクターの名前 |
| 年齢 | 任意の年齢 |
| 種族 | 人間、エルフ、獣人、悪魔、その他 |
| 性別 | 男性、女性、その他 |
| 能力 | キャラクターが持つ能力 |
| ストーリー | キャラクターの設定や背景 |

### 能力管理

キャラクターに能力を追加できます。

能力ごとに、以下の情報を設定します。

- 能力名
- 威力
- 能力タイプ
- 消費MP

能力タイプは、攻撃・回復・強化・弱体化を想定しています。

### データの保存

登録したキャラクター情報はファイルに保存されます。

アプリを終了して再起動しても、保存されたデータを読み込んで利用できます。

保存先にはアプリ専用のデータディレクトリを使用しており、ソースコードの作業ディレクトリとは分離しています。

## 起動方法

### 1. 必要な環境

- Rust
- Cargo

Rust は [公式サイト](https://www.rust-lang.org/tools/install) からインストールできます。

### 2. リポジトリを取得

```bash
git clone https://github.com/hororo0814/MyCharacterFile.git
cd https://github.com/hororo0814/MyCharacterFile.git
```


### 3. アプリを起動

```bash
cargo run
```

初回起動時は、依存関係の取得とビルドが行われます。

### 4. リリース用ビルド

最適化された実行ファイルを作成するには、次のコマンドを実行します。

```bash
cargo build --release
```

Windowsでは、通常、次の場所に実行ファイルが生成されます。

```text
target/release/オリジナルキャラクター図鑑.exe
```

実行ファイルの起動には、利用環境に応じた動作確認が必要です。

## データの保存先

キャラクターデータは、`directories` クレートを利用して取得したアプリ専用のデータディレクトリに `file.txt` として保存します。

保存先のディレクトリが存在しない場合は、必要に応じて作成します。

なお、アプリを削除する場合や別の環境に移行する場合は、保存データのバックアップにも注意してください。

## プロジェクト構成

```text
.
├── Cargo.toml
├── Cargo.lock
└── src
    ├── main.rs
    ├── domain
    │   ├── character.rs
    │   └── ability.rs
    │   └── mod.rs
    │   └── race.rs
    │   └── element.rs
    ├── repository
    │   ├── character_store.rs
    │   └── character_file.rs
    │   └── mod.rs
    └── ui
        └── app.rs
```

※ 実際のファイル構成に応じて、必要に応じて更新してください。

### 各モジュールの役割

- `main.rs`: アプリの起動処理
- `domain/`: キャラクターや能力などのドメインモデル
- `repository/character_store.rs`: キャラクターデータの管理
- `repository/character_file.rs`: ファイルへの保存・読み込み
- `ui/app.rs`: GUIとユーザー操作の処理
