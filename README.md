# オリジナルキャラクター図鑑

Rust と `egui` を使って開発している、オリジナルキャラクター管理用のデスクトップアプリです。キャラクターの登録・検索・編集・削除や、キャラクターが持つ能力の管理、データのファイル保存を行います。

このプロジェクトは、Rust の学習とデスクトップアプリ開発の練習を兼ねて、機能を段階的に実装しています。

## 主な機能

### キャラクター管理

- キャラクターの新規登録
- 登録済みキャラクターの一覧表示
- 名前による検索
- キャラクター情報の編集
- 削除確認ダイアログ付きのキャラクター削除

### 能力管理

- キャラクター登録時の初期能力設定
- 登録済みキャラクターへの能力追加
- 能力名、威力、能力タイプ、消費 MP の管理

※ 能力の個別削除・編集など、未実装の機能は今後の開発候補です。

### データ保存

- キャラクター情報をテキストファイルに保存
- 起動時に保存済みデータを読み込む
- アプリを再起動しても登録内容を保持

## 使用技術

- **Rust**：アプリケーションの実装
- **eframe / egui**：デスクトップ GUI
- **thiserror**：エラー型の実装
- **Cargo**：ビルド、テスト、依存関係の管理
